INTRODUÇÃO E VISÃO GERAL ## 1.1 O que é o SISPROCON? O **SISPROCON** (Sistema Integrado de Proteção ao Consumidor) é uma plataforma web completa desenvolvida para o **PROCON do Estado do Amazonas**. O sistema digitaliza e automatiza todos os processos relacionados à proteção e defesa do consumidor, desde o atendimento inicial até a conclusão de processos administrativos, incluindo fiscalização, aplicação de multas, e acompanhamento jurídico. ## 1.2 Objetivos do Sistema 1. **Digitalização Completa**: Eliminar processos manuais e em papel 2. **Gestão Integrada**: Unificar todos os setores do PROCON em uma única plataforma 3. **Transparência**: Permitir acompanhamento público de processos e reclamações 4. **Eficiência Operacional**: Automatizar fluxos de trabalho e notificações 5. **Business Intelligence**: Fornecer dados analíticos para tomada de decisão 6. **Compliance com LGPD**: Garantir proteção de dados pessoais dos cidadãos 7. **Auditoria Completa**: Rastreabilidade de todas as ações no sistema ## 1.3 Público-Alvo | Perfil | Funcionalidades | |--------|-----------------| | **Cidadão/Consumidor** | Portal para registrar reclamações, consultar processos, baixar formulários | | **Empresas** | Portal para responder reclamações, acompanhar notificações, regularizar situação | | **Atendentes** | Triagem de demandas, atendimento presencial, gestão de filas | | **Fiscais** | Autos de constatação, autos de infração, fiscalização em campo | | **Analistas Jurídicos** | Análise de processos, pareceres, recursos e defesas | | **Gestores/Diretores** | Dashboards executivos, relatórios, indicadores | | **TI/Administradores** | Gestão de usuários, permissões, logs, configurações | --- # 🏗️ 2. Docker / Docker Compose (Containerização) - Nginx (Proxy Reverso) - GitHub Actions (CI/CD) - Prometheus + Grafana (Monitoramento) ## 2.2 Diagrama de Arquitetura ``` ┌─────────────────────────────────────────────────────────────────────┐ │ CLIENTE (Browser) │ │ React SPA + TailwindCSS │ └────────────────────────────┬────────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────────────────┐ │ NGINX │ │ (Proxy Reverso + Arquivos Estáticos) │ └────────────────────────────┬────────────────────────────────────────┘ │ ┌──────────────┴──────────────┐ ▼ ▼ ┌─────────────────────────┐ ┌─────────────────────────┐ │ Django REST API │ │ Celery Workers │ │ (Gunicorn) │ │ (Tarefas Async) │ └───────────┬─────────────┘ └───────────┬─────────────┘ │ │ └───────────────┬───────────────┘ ▼ ┌───────────────────────────────┐ │ PostgreSQL │ │ (Banco Principal) │ └───────────────┬───────────────┘ │ ┌───────────────┴───────────────┐ ▼ ▼ ┌─────────────────────────┐ ┌─────────────────────────┐ │ Redis │ │ Prometheus │ │ (Cache/Sessions) │ │ (Métricas) │ └─────────────────────────┘ └─────────────────────────┘ ``` ## 2.3 Estrutura de Diretórios Principal ``` system_procon/ ├── 📁 procon_system/ # Backend Django │ ├── 📁 procon_system/ # Configurações do projeto │ ├── 📁 atendimento/ # Módulo de Atendimento │ ├── 📁 fiscalizacao/ # Módulo de Fiscalização │ ├── 📁 multas/ # Módulo de Multas │ ├── 📁 juridico/ # Módulo Jurídico │ ├── 📁 protocolo/ # Módulo de Protocolo │ ├── 📁 ppa/ # PPA - MÓDULOS DO SISTEMA ## 3.1 📱 MÓDULO DE ATENDIMENTO ### Descrição Gerencia todo o fluxo de atendimento presencial e remoto do PROCON. ### Modelos Principais - `BalcaoAtendimento` - Guichês de atendimento presencial - `Atendimento` - Registro de cada atendimento realizado - `FilaAtendimento` - Controle de filas por balcão - `ConfiguracaoAtendimento` - Parâmetros do sistema - `RegraDistribuicaoAtendimento` - Regras para distribuição automática ### Funcionalidades - Totem de autoatendimento para senhas - Painel TV para chamada de senhas - Fila de espera com prioridades - Registro de atendimentos com LGPD - Estatísticas de tempo de espera - Distribuição automática de reclamações - Classificação por gravidade (BAIXA, MÉDIA, ALTA) --- ## 3.2 🔍 MÓDULO DE FISCALIZAÇÃO ### Descrição Sistema completo para fiscalização de estabelecimentos comerciais. ### Modelos Principais - `AutoConstatacaoBase` - Classe base abstrata para autos - `AutoBanco` - Auto para agências bancárias - `AutoPosto` - Auto para postos de combustível - `AutoSupermercado` - Auto para supermercados - `AutoDiversos` - Auto para legislação diversa - `AutoInfracao` - Auto de infração - `Processo` - Processo administrativo ### Funcionalidades - Criação de autos com geolocalização - Leitura de código de barras de produtos - Captura de fotos e anexos - Assinatura digital do fiscal e responsável - Modo offline com sincronização - Geração automática de número sequencial - Fluxo para auto de infração --- ## 3.3 💰 MÓDULO DE MULTAS ### Descrição Gerenciamento completo do ciclo de vida de multas aplicadas pelo PROCON. ### Modelos Principais - `Multa` - Registro principal da multa - `Cobranca` - Tentativas de cobrança - `Peticao` - Petições recebidas - `Recurso` - Recursos impetrados - `Analise` - Análises de recursos ### Status da Multa PENDENTE, NOTIFICADA, QUITADA, PARCELADA, CANCELADA, EM_RECURSO, EM_EXECUCAO_FISCAL ### Funcionalidades - Geração automática de multas a partir de processos - Cálculo de juros e correção monetária - Notificações automáticas de vencimento - Registro de pagamentos - Fluxo de recursos (1ª e 2ª instância) --- ## 3.4 ⚖️ MÓDULO JURÍDICO ### Descrição Suporte completo ao setor jurídico do PROCON. ### Modelos Principais - `AnalistaJuridico` - Perfil do analista jurídico - `ProcessoJuridico` - Processo jurídico principal - `AnaliseJuridica` - Análise técnica do processo - `RespostaJuridica` - Respostas formais - `PrazoJuridico` - Controle de prazos processuais - `DocumentoJuridico` - Documentos anexados ### Funcionalidades - Gestão de processos jurídicos - Controle de prazos com alertas - Elaboração de pareceres e análises - Gestão de documentos por processo - Histórico completo de tramitações --- ## 3.5 📂 MÓDULO DE PROTOCOLO ### Descrição Sistema de protocolo único para todos os documentos do PROCON. ### Modelos Principais - `TipoProtocolo` - Tipos de protocolo disponíveis - `StatusProtocolo` - Status possíveis - `Protocolo` - Registro principal - `DocumentoProtocolo` - Documentos anexados - `TramitacaoProtocolo` - Histórico de tramitação ### Funcionalidades - Geração automática de número de protocolo - Formato configurável (PROT-{ANO}-{SEQUENCIAL}) - Controle de prazos por tipo - Tramitação entre setores/responsáveis - Anexação de documentos com validação --- ## 3.6 📋 MÓDULO PPA (Procedimento Preliminar Administrativo) ### Descrição Gerencia o PPA - "capa" do processo onde são anexados todos os documentos. ### Modelos Principais - `ProcedimentoPreAdministrativo` - PPA principal - `MovimentacaoPPA` - Registro de eventos/movimentações - `AnexoPPA` - Documentos anexados ao PPA - `ParecerPPA` - Parecer técnico elaborado ### Tipos de Anexo AC (Auto de Constatação), AI (Auto de Infração), NOT (Notificação), DEF (Defesa), RAZ (Razões Finais), PAR (Parecer Técnico), DEC (Decisão), DOC (Documento Geral) ### Funcionalidades - Criação automática de PPA a partir de AC/AI - Vinculação genérica de documentos - Timeline de movimentações - Geração de pareceres técnicos - Exportação em Word/PDF --- ## 3.7 📥 MÓDULO CAIXA DE ENTRADA ### Descrição Sistema de caixa de entrada unificada, similar ao SIGED. ### Modelos Principais - `CaixaEntrada` - Documento na caixa de entrada - `AnexoCaixaEntrada` - Anexos do documento - `HistoricoCaixaEntrada` - Histórico de ações - `PermissaoSetorCaixaEntrada` - Permissões por setor ### Setores ATENDIMENTO, FISCALIZACAO, JURIDICO, DIRETORIA, DAF, TI ### Funcionalidades - Visualização por setor (caixa pessoal e do setor) - Distribuição automática ou manual - Controle de prazos de resposta - Encaminhamento entre setores - Alertas de documentos atrasados --- ## 3.8 🎫 MÓDULO DE TRIAGEM ### Descrição Centraliza a triagem de todas as demandas que chegam ao PROCON. ### Modelos Principais - `TriagemDemanda` - Registro da triagem - `TriagemAnexo` - Arquivos anexados - `TriagemHistorico` - Histórico de eventos ### Origens PORTAL, TELEFONE, PRESENCIAL, EMAIL, OFICIO, REPRESENTACAO ### Funcionalidades - Recepção de demandas do portal - Classificação automática de prioridade - Encaminhamento para fiscalização - Agendamento automático de fiscalização - Criação de PPA a partir da triagem --- ## 3.9 💳 MÓDULO DE COBRANÇA ### Descrição Gestão completa de cobranças de multas. ### Modelos Principais - `ConfiguracaoCobranca` - Parâmetros do sistema - `BoletoMulta` - Boletos gerados - `PagamentoMulta` - Registro de pagamentos - `CobrancaMulta` - Tentativas de cobrança ### Funcionalidades - Geração automática de boletos - Cálculo de juros e multa por atraso - Geração de código PIX (EMV) - Código de barras padronizado - Registro e confirmação de pagamentos --- ## 3.10 🔔 MÓDULO DE NOTIFICAÇÕES ### Descrição Sistema centralizado de notificações multicanal. ### Modelos Principais - `TipoNotificacao` - Tipos disponíveis - `Notificacao` - Notificação principal - `PreferenciaNotificacao` - Preferências por usuário - `DispositivoNotificacao` - Tokens para push - `TemplateNotificacao` - Templates de mensagem ### Canais email, sms, push, sistema ### Funcionalidades - Múltiplos canais de envio - Templates configuráveis com variáveis - Agendamento de envio - Push para mobile (Android/iOS/Web) --- ## 3.11 📊 MÓDULO DE BUSINESS INTELLIGENCE ### Descrição Dashboards executivos, KPIs governamentais e análises avançadas. ### Modelos Principais - `KPI` - Indicadores de desempenho - `Dashboard` - Dashboards configuráveis - `ValorKPI` - Histórico de valores - `RelatorioPersonalizado` - Relatórios customizados ### Tipos de Dashboard EXECUTIVO, OPERACIONAL, TATICO, GERENCIAL ### Funcionalidades - KPIs governamentais configuráveis - Dashboards por perfil de usuário - Gráficos e visualizações - Relatórios automatizados - Exportação Excel/PDF --- ## 3.12 🌐 PORTAL DO CIDADÃO ### Descrição Interface pública para cidadãos acessarem serviços do PROCON. ### Modelos Principais - `PerfilCidadao` - Perfil do cidadão cadastrado - `ConteudoPortal` - Artigos, FAQs, tutoriais - `FormularioPublico` - Formulários para download - `DenunciaCidadao` - Denúncias anônimas ou identificadas - `ReclamacaoCidadao` - Reclamações formais ### Funcionalidades - Registro de reclamações online - Denúncia anônima - Consulta de processos - Acompanhamento de reclamações - Download de formulários - Ranking de empresas - Pesquisa de preços --- ## 3.13 🏢 PORTAL DA EMPRESA ### Funcionalidades - Login com CNPJ - Visualização de reclamações - Resposta a reclamações - Upload de documentos - Consulta de notificações - Pagamento de multas --- ## 3.14 📝 MÓDULO DE AUDITORIA ### Descrição Sistema completo de logs e auditoria. ### Modelos Principais - `TipoEvento` - Tipos de eventos auditáveis - `LogSistema` - Log geral do sistema - `AuditoriaAlteracao` - Alterações em registros - `SessaoUsuario` - Sessões de login - `AcessoRecurso` - Acessos a recursos ### Funcionalidades - Log de todas as ações - Rastreamento de alterações - Registro de sessões de usuário - Controle de acessos - Exportação de logs --- # 🔐 4.
